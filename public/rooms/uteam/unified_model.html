Integrated Framework

The Unified U-TEAM Model connects teach4TEC and teach4PHI into a common methodological framework for cross-disciplinary university teaching.

Core Dimensions

  • Learner
  • Disciplinary knowledge
  • Learning outcomes
  • Learning activities
  • Guidance and interaction
  • Evidence and feedback
  • Reflection and improvement

Implementation Logic

Context → learning needs → methodology → teaching scenario → implementation → evidence → improvement.
